ARCHIVE 1025 V18 변경사항

1. 오프닝을 3단계 사건 브리핑으로 개편
   - 비인가 침입 감지 → 기록관 봉쇄 → 플레이어 임무 제시
   - 브리핑 이후 난이도 선택

2. CASE 01 구조 개편
   - 독도 지도 클릭 시 실제 지도 자료 + '관계 없음' 기록 카드 획득
   - 잘못된 문구는 지도에서 고치는 것이 아니라 방 중앙 기록 복원기에서 수정
   - 입문자 모드: 핵심 카드 2장 중심으로 축소
   - 도전자 모드: 여러 문자 카드를 직접 걸러내는 구조 유지

3. CASE 02 도전자 모드 강화
   - 침입자 메모에서 1905 숫자 및 완성된 디지털 숫자 형태를 완전히 제거
   - 오직 화살표 방향 묶음만 표시
   - 도전자 입력 과정에서도 선을 그리지 않고 누른 화살표만 출력
   - 입문자 모드는 기존 숫자/선 보조 유지

4. 엔딩 UI 개편
   - 'CASE CLOSED/탈출 성공' 중심 표현 대신 '기록관 복원 완료'로 정리
   - 1025 = 10월 25일의 의미를 중앙에 명확하게 설명
   - 세 사건의 핵심 기록을 간결하게 정리

5. 팝업/카드 UI 정돈
   - 본문 폭, 선택 상자, 버튼 정렬, 카드 트레이 최대 너비 통일
   - 중학생 태블릿 가독성을 고려한 여백과 문장 길이 조정
