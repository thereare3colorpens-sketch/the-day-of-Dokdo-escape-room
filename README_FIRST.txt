[배포]
1. 이 폴더 안의 파일/폴더 전체를 GitHub 저장소 루트에 업로드합니다.

[플레이 순서]
학년도·학번·난이도 입력 → 시네마틱 사건 브리핑 → ROOM 1 → ROOM 2 → FINAL CASE → 기록관 복원 완료

[V19 핵심]
- 방이 열릴 때 큰 '비밀 통로 개방' 문구를 띄우지 않습니다. 실제 방 이미지 변화, 먼지, 광원, 효과음으로만 연출합니다.
- 마지막 정밀 크로노미터에는 '확인' 버튼이 없습니다. 10:25가 맞으면 장치가 자동 반응합니다.
- FINAL CASE 안내문은 시계 정답을 직접 말하지 않고 '날을 찾아 기록으로 남긴다'는 방향으로 설계했습니다.
- 일반 힌트 최초 사용 +30초, 오브젝트 표시 최초 사용 +45초. 같은 힌트 반복 사용은 추가 보정하지 않습니다.
- 결과 화면에 실제 시간 / 힌트 보정 / 비교 기록을 함께 표시합니다.
- Firebase를 연결하면 학년도, 학번, 난이도, 실제 시간, 보정 시간, 방별 시간, 힌트 사용 내역이 자동 저장됩니다.
